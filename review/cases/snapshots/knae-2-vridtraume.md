# knae-2-vridtraume

**Vridtraume med straks hævelse og instabilitet (scenarie A)** (rødt flag)

## Input

- side = venstre
- debut = akut
- varighed = dage
- traume = ja
- traumemekanisme = vrid
- haevelse-straks = ja
- knaek = ja
- alder = 12til50
- belastning = reduceret
- haevelse = moderat
- stabilitet = instabil
- patellaoemhed = nej
- fibulaoemhed = nej
- fleksion90 = ja
- skridt = ja
- benloeft = ja

Afkrydset (V/P): diff-acl, hen-akut-traume

## Notat

```
S: Venstresidige knæsmerter. Akut debut. Varighed få dage. Forudgående traume. Traume ved vrid. Hævelse opstod umiddelbart efter traumet. Hørt eller følt et knæk ved traumet. Reduceret belastningsevne.
O: Moderat hævelse. Klinisk mistanke om instabilitet. Ingen direkte ømhed på patella. Ingen ømhed på caput fibulae. Kan flektere knæet til 90 grader. Går fire vægtbærende skridt ved undersøgelsen. Kan løfte strakt ben mod tyngdekraften.
V: Foreneligt med skade på forreste korsbånd.
P: Henvist akut til CVI.
```

## Røde flag (10, alle vises altid)

- [MATCHER] Akut ligamentskade eller stor ledansamling (flag-akut-ligamentskade, GODKENDT)
- [ikke vurderet] Bakteriel artrit (flag-bakteriel-artrit, GODKENDT)
- [ikke opfyldt af registreret] Akut knæskade (flag-fraktur, GODKENDT)
- [ikke vurderet] Aflåst knæ (flag-aflaast-knae, UDKAST)
- [ikke opfyldt af registreret] Strækkeapparat (flag-straekkeapparat, GODKENDT)
- [(ingen betingelse)] Akut patellaluksation (flag-patellaluksation, GODKENDT)
- [(ingen betingelse)] Store og akutte knæskader (flag-stor-akut-skade, GODKENDT)
- [ikke vurderet] Bursit med stærke smerter, varme, rødme, kraftig hævelse og feber indi (flag-septisk-bursit, GODKENDT)
- [(ingen betingelse)] Akut indsættende hævelse og evt. rødme i øvre læg kan være en bristet  (flag-laeg-haevelse, GODKENDT)
- [ikke opfyldt af registreret] Barn med knæsmerter – diagnostiske faldgruber (flag-boern, UDKAST)

## Differentialdiagnoser (15, statisk liste)

- Gonartrose (diff-artrose)
- Meniskskade / meniskdegeneration (diff-menisk)
- [V] Forreste korsbåndsskade (diff-acl)
- Skade på mediale kollaterale ligament (diff-mcl)
- Patellofemoralt smertesyndrom (diff-patellofemoralt)
- Patellaluksation (akut eller recidiverende) (diff-patellaluksation)
- Tendinopati / overbelastning (diff-tendinopati)
- Knæbursit (præpatellar / infrapatellar) (diff-bursit)
- Bakers cyste (diff-baker)
- Bakteriel artrit (diff-bakteriel-artrit)
- Artrit (krystalartrit, reaktiv, reumatisk) (diff-artrit)
- Henført smerte fra hofte eller ryg (diff-henfoert)
- Osteochondritis dissecans (diff-ocd)
- Osgood-Schlatter / Sinding-Larsen (diff-apofysit)
- Ikke-artikulær hævelse (erysipelas, dyb venetrombose, senelidelse) (diff-ikke-artikulaer)
