# albue-2-fald-caput-radii

**Fald på strakt arm, nedsat ekstension, øm caput radii** (rødt flag)

## Input

- side = venstre
- debut = traume
- mekanisme = fald
- lokalisation = lateral
- varighed = dage
- fejlstilling = nej
- haevelse = led
- ekstensionstest = nedsat
- caputradii = oem
- neurovaskulaer = normal

Afkrydset (V/P): diff-caput-radii, hen-akut-traume

## Notat

```
S: Venstresidige albuesmerter. Opstået efter traume. Fald på strakt arm. Smerter lateralt på albuen. Varighed få dage.
O: Ingen fejlstilling. Hævelse af leddet eller hæmatom. Albue-ekstensionstest: nedsat ekstension. Palpationsømhed over caput radii. Palpabel radialispuls; normal sensibilitet og motorik svarende til n. ulnaris, medianus og radialis.
V: Caput radii fraktur mistænkes.
P: Henvist akut til akutmodtagelsen efter albuetraume.
```

## Røde flag (6, alle vises altid)

- [MATCHER] Fraktur eller luksation efter traume (ofte fald på strakt arm) (flag-fraktur-luksation, GODKENDT)
- [ikke opfyldt af registreret] Neurovaskulær påvirkning ved fraktur eller luksation (flag-neurovaskulaer, GODKENDT)
- [ikke opfyldt af registreret] Muskel-seneskade efter hyperekstensions- eller hyperfleksionstraume (flag-muskelsene, GODKENDT)
- [ikke vurderet] Septisk artrit eller hæmartrose efter traume (flag-septisk, GODKENDT)
- [ikke opfyldt af registreret] Septisk bursitis olecrani hos patient med albueprotese eller reumatoid (flag-septisk-bursit, GODKENDT)
- [(ingen betingelse)] Diagnostiske faldgruber (flag-faldgruber, GODKENDT)

## Differentialdiagnoser (11, statisk liste)

- Lateral epikondylit (tennisalbue) (diff-lateral-epikondylit)
- Medial epikondylit (golfalbue) (diff-medial-epikondylit)
- Bursitis olecrani (aseptisk eller septisk) (diff-bursit)
- Ulnarisneuropati (diff-ulnaris)
- Kompression af n. radialis (radialt tunnelsyndrom / supinatorsyndrom) (diff-radialis)
- [V] Caput radii fraktur (diff-caput-radii)
- Anden albuefraktur eller albueluksation (diff-fraktur-luksation)
- Bruskskade / osteochondritis dissecans / løst legeme (diff-brusk)
- Biceps tendinose (diff-biceps-tendinose)
- Medial ligamentskade (ulnare kollateralligament) (diff-medial-ligament)
- Henført smerte (cervikal radikulopati, skulder, håndled) (diff-henfoert)

## Henvisning (7, statisk liste)

- [P] Akutmodtagelsen · akut (hen-akut-traume)
- Akut indlæggelse (ortopædkirurgi via CVI) · akut (hen-septisk)
- Ortopædkirurgisk afdeling (bursitis olecrani) · subakut (hen-bursit)
- Ortopædkirurgi · elektiv (hen-epikondylit)
- Neurolog · elektiv (hen-ulnaris)
- Albuespecialist / ortopædkirurgisk afdeling · elektiv (hen-caput-radii-sen)
- Ortopædkirurgisk ambulatorium · elektiv (hen-komplikationer)
