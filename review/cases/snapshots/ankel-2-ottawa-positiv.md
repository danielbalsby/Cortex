# ankel-2-ottawa-positiv

**Inversionstraume med knogleømhed over laterale malleol** (rødt flag)

## Input

- side = venstre
- mekanisme = inversion
- varighed = timer
- skridt-straks = nej
- skridt-nu = ja
- haevelse = lateral
- malleol = lateral

Afkrydset (V/P): diff-fraktur, hen-samme-dag

## Notat

```
S: Venstresidige ankelsmerter. Indadvridningstraume (inversion). Varighed timer. Kunne ikke gå fire vægtbærende skridt umiddelbart efter skaden.
O: Går fire vægtbærende skridt ved undersøgelsen. Hævelse lateralt. Knogleømhed over laterale malleol (bagkant/spids, nederste 6 cm).
V: Fraktur mistænkes.
P: Henvist samme dag til akut vurdering.
```

## Røde flag (7, alle vises altid)

- [MATCHER] Fraktur (Ottawa-reglerne) (flag-fraktur, GODKENDT)
- [ikke vurderet] Truet ben (flag-straks, GODKENDT)
- [ikke vurderet] Akillesseneruptur (flag-akilles, GODKENDT)
- [ikke vurderet] Syndesmose- eller Maisonneuve-skade (flag-syndesmose, GODKENDT)
- [ikke vurderet] Akut artrit, herunder infektion (flag-artrit, GODKENDT)
- [ikke vurderet] Diabetes eller nedsat følesans (flag-neuropati, GODKENDT)
- [ikke opfyldt af registreret] Stressfraktur (flag-stressfraktur, GODKENDT)

- [V] Fraktur (malleol, fod eller bagfod) (diff-fraktur)

- Medial ligamentskade (lig. deltoideum) (diff-medial)
