# ankel-3-akilles

**Smæld i læggen ved afsæt, positiv Thompson** (rødt flag)

## Input

- side = hoejre
- mekanisme = smaeld
- varighed = timer
- skridt-nu = ja
- akilles = positiv

Afkrydset (V/P): diff-akilles, beh-akilles-skinne, hen-samme-dag

## Notat

```
S: Højresidige ankelsmerter. Smæld eller følelse af spark bag på læggen ved afsæt. Varighed timer.
O: Går fire vægtbærende skridt ved undersøgelsen. Positiv Simmonds-Thompson-test eller palpabel defekt i akillessenen.
V: Akillesseneruptur mistænkes.
P: Anklen plantarflekteret i skinne indtil vurdering. Henvist samme dag til akut vurdering.
```

## Røde flag (7, alle vises altid)

- [MATCHER] Akillesseneruptur (flag-akilles, GODKENDT)
- [ikke vurderet] Truet ben (flag-straks, GODKENDT)
- [ikke vurderet] Fraktur (Ottawa-reglerne) (flag-fraktur, GODKENDT)
- [ikke vurderet] Syndesmose- eller Maisonneuve-skade (flag-syndesmose, GODKENDT)
- [ikke vurderet] Akut artrit, herunder infektion (flag-artrit, GODKENDT)
- [ikke vurderet] Diabetes eller nedsat følesans (flag-neuropati, GODKENDT)
- [ikke opfyldt af registreret] Stressfraktur (flag-stressfraktur, GODKENDT)

## Differentialdiagnoser (11, statisk liste)

- Lateral ankeldistorsion (diff-distorsion)
- Fraktur (malleol, fod eller bagfod) (diff-fraktur)
- Syndesmoseskade / Maisonneuve-skade (diff-syndesmose)
- Medial ligamentskade (lig. deltoideum) (diff-medial)
- [V] Akillesseneruptur (diff-akilles)
- Anden seneskade / peroneusluksation (diff-sene)
- Stressfraktur (diff-stressfraktur)
- Osteokondral skade (bruskskade i anklen) (diff-brusk)
- Kronisk lateral ankelinstabilitet (diff-instabilitet)
- Akut artrit, herunder septisk (diff-artrit)
- Ikke-artikulær hævelse (erysipelas, dyb venetrombose, senelidelse) (diff-ikke-artikulaer)

## Henvisning (8, statisk liste)

- Fysioterapi · elektiv (hen-fys)
- Akut vurdering / indlæggelse straks · akut (hen-straks)
- [P] Røntgen eller akutmodtagelse samme dag · akut (hen-samme-dag)
- Billeddiagnostik eller ortopædkirurgisk vurdering (hurtigt) · subakut (hen-hurtig)
- Ortopædkirurg · elektiv (hen-langvarig)
- Ortopædkirurg (bruskskade) · elektiv (hen-brusk)
- Ortopædkirurg (instabilitet) · elektiv (hen-instabilitet)
- Akut indlæggelse (ortopædkirurgi via CVI) · akut (hen-septisk)
