# ryg-1-uspecifik

**Akutte lændesmerter efter løft, ingen udstråling** (ukompliceret)

## Input

- udbredning = laend
- debut = akut
- varighed = dage
- tidligere = lignende
- cauda = nej
- almen = upaavirket
- holdning = normal
- bevaegelighed = nedsat
- lasegue = neg
- kraft = normal
- reflekser = normale
- sensibilitet = normal

Afkrydset (V/P): diff-uspecifik, beh-aktivitet, beh-medicin-akut

## Notat

```
S: Smerter i lænden uden udstråling. Akut debut ved løft eller vrid. Varighed få dage. Tidligere lignende episoder. Ingen vandladnings- eller afføringsforstyrrelser og ingen føleforstyrrelser i ridebukseområdet.
O: Upåvirket almentilstand. Normal gang og holdning. Nedsat bevægelighed i lænderyggen. Negativ Lasègue bilateralt. Normal kraft i underekstremiteterne. Normale og symmetriske patellar- og achillesreflekser. Normal sensibilitet i underekstremiteterne.
V: Foreneligt med uspecifikke lænderygsmerter.
P: Informeret om den gode prognose. Opfordret til at fortsætte vanlig aktivitet. Opfølgning om 1–2 uger. Paracetamol og NSAID efter behov.
```

## Røde flag (8, alle vises altid)

- [ikke vurderet] Cauda equina eller betydende nyopstået parese (flag-cauda, GODKENDT)
- [ikke vurderet] Mulig malignitet (flag-malignitet, GODKENDT)
- [ikke vurderet] Mulig infektion (spondylodiscitis) (flag-infektion, GODKENDT)
- [ikke vurderet] Mulig fraktur (flag-fraktur, GODKENDT)
- [ikke opfyldt af registreret] Udbredte og evt. progredierende neurologiske udfald, eller deformitet  (flag-udbredte-udfald, GODKENDT)
- [ikke vurderet] Mulig inflammatorisk rygsygdom (flag-inflammatorisk, GODKENDT)
- [(ingen betingelse)] Smerter fra indre organer (flag-indre-organer, GODKENDT)
- [(ingen betingelse)] Øvrige forhold i anamnesen ved akutte rygsmerter (flag-oevrige-alarm, GODKENDT)

## Differentialdiagnoser (10, statisk liste)

- [V] Uspecifikke lænderygsmerter (diff-uspecifik)
- Lumbal rodaffektion / diskusprolaps (diff-rod)
- Cauda equina-syndrom (diff-cauda)
- Lumbal spinalstenose (diff-stenose)
- Vertebralt kompressionsbrud (diff-sammenfald)
- Spondylartrit / Bechterews sygdom (diff-spa)
- Malignitet (metastaser, myelomatose, spinal tumor) (diff-malignitet)
- Infektion (spondylodiscitis) (diff-infektion)
- Spondylolistese (diff-spondylolistese)
- Anden årsag til ben- og lændesmerter (diff-andet)

## Henvisning (11, statisk liste)

- Akut indlæggelse via CVI · akut (hen-cauda)
- Reumatologisk hotline · subakut (hen-hotline)
- Akutmodtagelse / pakkeforløb · akut (hen-infektion-malignitet)
- Rygsektionen, Rigshospitalet (konference) / Akut Modtagelse · akut (hen-fraktur)
- Fysioterapeut eller kiropraktor · elektiv (hen-fys)
- MR af columna lumbalis (fra almen praksis) · elektiv (hen-mr)
- Rygkirurgisk vurdering · elektiv (hen-rod-kirurgi)
- Reumatologisk rygfunktion, Rigshospitalet, Valdemar Hansens Vej (elektiv) · elektiv (hen-reumatologi)
- Lokal neurologisk eller rygmedicinsk afdeling · elektiv (hen-stenose)
- Reumatolog (hospital eller speciallægepraksis) · elektiv (hen-spa)
- Rygkirurgisk funktion, Glostrup · subakut (hen-recidiv)
