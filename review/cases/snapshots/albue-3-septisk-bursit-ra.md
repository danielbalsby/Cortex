# albue-3-septisk-bursit-ra

**Reumatoid artrit, rød hævelse over olecranon** (rødt flag)

## Input

- side = hoejre
- debut = spontan
- lokalisation = bagtil
- varighed = dage
- disposition = ra
- haevelse = bursa
- roedme = ja

Afkrydset (V/P): diff-bursit, hen-bursit

## Notat

```
S: Højresidige albuesmerter. Opstået uden kendt årsag. Smerter bagtil på albuen. Varighed få dage. Reumatoid artrit.
O: Væskefyldt hævelse over olecranon. Rødme og varmeøgning.
V: Foreneligt med bursitis olecrani.
P: Henvist til ortopædkirurgisk afdeling mhp. bursitis olecrani.
```

## Røde flag (6, alle vises altid)

- [MATCHER] Septisk bursitis olecrani hos patient med albueprotese eller reumatoid (flag-septisk-bursit, GODKENDT)
- [ikke vurderet] Fraktur eller luksation efter traume (ofte fald på strakt arm) (flag-fraktur-luksation, GODKENDT)
- [ikke vurderet] Neurovaskulær påvirkning ved fraktur eller luksation (flag-neurovaskulaer, GODKENDT)
- [ikke vurderet] Muskel-seneskade efter hyperekstensions- eller hyperfleksionstraume (flag-muskelsene, GODKENDT)
- [ikke opfyldt af registreret] Septisk artrit eller hæmartrose efter traume (flag-septisk, GODKENDT)
- [(ingen betingelse)] Diagnostiske faldgruber (flag-faldgruber, GODKENDT)

## Differentialdiagnoser (11, statisk liste)

- Lateral epikondylit (tennisalbue) (diff-lateral-epikondylit)
- Medial epikondylit (golfalbue) (diff-medial-epikondylit)
- [V] Bursitis olecrani (aseptisk eller septisk) (diff-bursit)
- Ulnarisneuropati (diff-ulnaris)
- Kompression af n. radialis (radialt tunnelsyndrom / supinatorsyndrom) (diff-radialis)
- Caput radii fraktur (diff-caput-radii)
- Anden albuefraktur eller albueluksation (diff-fraktur-luksation)
- Bruskskade / osteochondritis dissecans / løst legeme (diff-brusk)
- Biceps tendinose (diff-biceps-tendinose)
- Medial ligamentskade (ulnare kollateralligament) (diff-medial-ligament)
- Henført smerte (cervikal radikulopati, skulder, håndled) (diff-henfoert)

## Henvisning (7, statisk liste)

- Akutmodtagelsen · akut (hen-akut-traume)
- Akut indlæggelse (ortopædkirurgi via CVI) · akut (hen-septisk)
- [P] Ortopædkirurgisk afdeling (bursitis olecrani) · subakut (hen-bursit)
- Ortopædkirurgi · elektiv (hen-epikondylit)
- Neurolog · elektiv (hen-ulnaris)
- Albuespecialist / ortopædkirurgisk afdeling · elektiv (hen-caput-radii-sen)
- Ortopædkirurgisk ambulatorium · elektiv (hen-komplikationer)
