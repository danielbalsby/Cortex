# albue-1-lateral-epikondylit

**Laterale albuesmerter i uger ved overbelastning** (ukompliceret)

## Input

- side = hoejre
- debut = overbelastning
- lokalisation = lateral
- varighed = uger
- paraestesier = nej
- haevelse = ingen
- bevaegelighed = normal
- epikondyl = lateral
- isometrisk = ekstension
- ulnaris = normal

Afkrydset (V/P): diff-lateral-epikondylit, beh-epik-aflastning-traening

## Notat

```
S: Højresidige albuesmerter. Opstået efter overbelastning. Smerter lateralt på albuen. Varighed flere uger. Ingen paræstesier.
O: Ingen hævelse. Normal bevægelighed i albuen. Ømhed over laterale epikondyl. Smerter ved isometrisk ekstension og radial deviation af håndleddet med strakt albue. Normal sensibilitet i 4.–5. finger og normal kraft i ulnarisinnerverede muskler.
V: Foreneligt med lateral epikondylit.
P: Rådgivet om aflastning. Instrueret i excentriske øvelser og udspænding.
```

## Røde flag (6, alle vises altid)

- [ikke vurderet] Fraktur eller luksation efter traume (ofte fald på strakt arm) (flag-fraktur-luksation, GODKENDT)
- [ikke vurderet] Neurovaskulær påvirkning ved fraktur eller luksation (flag-neurovaskulaer, GODKENDT)
- [ikke vurderet] Muskel-seneskade efter hyperekstensions- eller hyperfleksionstraume (flag-muskelsene, GODKENDT)
- [ikke opfyldt af registreret] Septisk artrit eller hæmartrose efter traume (flag-septisk, GODKENDT)
- [ikke opfyldt af registreret] Septisk bursitis olecrani hos patient med albueprotese eller reumatoid (flag-septisk-bursit, GODKENDT)
- [(ingen betingelse)] Diagnostiske faldgruber (flag-faldgruber, GODKENDT)

## Differentialdiagnoser (11, statisk liste)

- [V] Lateral epikondylit (tennisalbue) (diff-lateral-epikondylit)
- Medial epikondylit (golfalbue) (diff-medial-epikondylit)
- Bursitis olecrani (aseptisk eller septisk) (diff-bursit)
- Ulnarisneuropati (diff-ulnaris)
- Kompression af n. radialis (radialt tunnelsyndrom / supinatorsyndrom) (diff-radialis)
- Caput radii fraktur (diff-caput-radii)
- Anden albuefraktur eller albueluksation (diff-fraktur-luksation)
- Bruskskade / osteochondritis dissecans / løst legeme (diff-brusk)
- Biceps tendinose (diff-biceps-tendinose)
- Medial ligamentskade (ulnare kollateralligament) (diff-medial-ligament)
- Henført smerte (cervikal radikulopati, skulder, håndled) (diff-henfoert)
