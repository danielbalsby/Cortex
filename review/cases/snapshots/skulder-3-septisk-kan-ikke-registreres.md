# skulder-3-septisk-kan-ikke-registreres

**Ældre med spontane hvilesmerter og nedsat bevægelighed; feber nævnt i fritekst** (rødt flag, kan ikke registreres)

## Input

- side = hoejre
- alder = over75
- debut = spontan
- varighed = dage
- nat = hvile
- anamnese-tekst = Feber siden i går
- aktiv = nedsat
- passiv = nedsat

## Notat

```
S: Højresidige skuldersmerter. Alder over 75 år. Spontant opståede gener. Varighed få dage. Hvilesmerter og natlige smerter. Feber siden i går.
O: Nedsat aktiv bevægelighed. Nedsat passiv bevægelighed.
```

## Røde flag (6, alle vises altid)

- [ikke vurderet] Akut skulderluksation (flag-luksation, GODKENDT)
- [ikke opfyldt af registreret] Brud eller seneruptur efter kraftigt traume eller overbelastning (flag-fraktur, GODKENDT)
- [ikke opfyldt af registreret] Traumatisk rotator cuff-ruptur (tidskritisk) (flag-traumatisk-cuff, GODKENDT)
- [ikke vurderet] Over 40 år efter skulderluksation (flag-cuff-efter-luksation, GODKENDT)
- [ikke vurderet] Diagnostiske faldgruber (flag-faldgruber, GODKENDT)
- [ikke vurderet] Septisk artrit (flag-septisk, GODKENDT)

## Differentialdiagnoser (10, statisk liste)

- Subacromielt smertesyndrom / rotator cuff-tendinopati (impingement) (diff-impingement)
- Akut bursit (evt. bursitis calcarea) (diff-bursit)
- Kapsulit (frossen skulder) (diff-kapsulit)
- Traumatisk rotator cuff-ruptur (diff-traumatisk-cuff)
- Degenerativ (ikke-traumatisk) rotator cuff-skade (diff-degenerativ-cuff)
- Skulderluksation / posttraumatisk instabilitet (diff-instabilitet)
- AC-ledslidelse (artrose, artrit, ledbåndsskade) (diff-ac)
- Artrose i glenohumeralleddet (diff-gh-artrose)
- Cervikal lidelse / radikulopati (diff-cervikal)
- Indklemning af n. suprascapularis (diff-suprascapularis)

## Henvisning (12, statisk liste)

- Hospital (skadestue) · akut (hen-luksation-akut)
- Røntgen af skulder · akut (hen-traume-roentgen)
- Ultralydsscanning af skulder · subakut (hen-ul)
- Ortopædkirurgisk afdeling (traumatisk rotator cuff-ruptur) · subakut (hen-traumatisk-cuff)
- Ultralyd eller ortopædkirurg · subakut (hen-cuff-efter-luksation)
- Skulderspecialist (ortopædkirurg) · elektiv (hen-instabilitet)
- Ortopædkirurgisk afdeling (impingement / ikke-traumatisk cuff-lidelse) · elektiv (hen-impingement)
- Ortopædkirurg · elektiv (hen-kapsulit)
- Ortopædkirurg (AC-ledsresektion) · elektiv (hen-ac)
- Arbejdsmedicinsk afdeling · elektiv (hen-arbejdsmedicin)
- Idrætsmedicinsk afdeling · elektiv (hen-idraet)
- Akut indlæggelse (ortopædkirurgi via CVI) · akut (hen-septisk)
