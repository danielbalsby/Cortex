# Architecture decisions

This directory contains Architecture Decision Records (ADRs). Each record must
state its lifecycle status; a `Proposed` ADR is neither accepted nor
implemented.

Initial proposed records:

- [ADR-001 — Repository Structure](ADR-001-Repository-Structure.md)
- [ADR-002 — Canonical Governance Sources](ADR-002-Canonical-Governance-Sources.md)
- [ADR-003 — Traceability Model](ADR-003-Traceability-Model.md)

Broader architectural proposals may still begin under
[`../rfcs/`](../rfcs/). The current pre-adoption architecture is documented in
[`../README.md`](../README.md).
