## Seneste beslutninger

- PDR-011 definerer præcis én C3.2 Fast Flow-hypotese efter C3.1's visuelle beståelse og flow-/tidsmæssige ikke-beståelse; API-018 er accepteret, scenarioet er locked, og C32-PBH-001 er Product-released til Steering.
- PDR-010 lukker C2.2 som `TECHNICALLY PASSED — NO MARKED PRODUCT GAIN`; API-017 har kvalificeret én C3 som `BUILDABLE AS BOUNDED C3 — MATERIAL CONSTRAINTS`, den kliniske phrase review er godkendt uden ændringer, og Product-handoffet er released til Steering.
- PDR-009 prioriterer Sprint 1.2 omkring IA-comparison, uncertainty-state-forståelse, cardinality/discoverability og adaptiv recovery; one-page og state simplification er hypoteser, ikke krav.
- PDR-008 prioriterer Sprint 1.1 omkring anamnese, objektiv granularitet, journal communication, safety comprehension og målt friktion; Architecture submission og Build er ikke autoriseret.
- PDR-007 fastlægger Sprint 1 som en assessment-centreret Product-iteration og forbereder Architecture-handoff; Build er ikke autoriseret.
- PDR-006 etablerer Experience Vision som DRAFT. Architecture review er completed som `CONFORMANT WITH REQUIRED PRODUCT REVISIONS`; fem material Product-revisioner udestår.
- PDR-005 reconciler Domain Architecture og åbnede Experience Vision-gatet.
- PDR-004 etablerer repositoryet som permanent Product-hukommelse og registrerer adoptionen af de lokale arbejdsudkast.
- PDR-003 kvalificerer Architecture Foundation: `Proposed` er ikke aktivt; Domain Architecture er et non-active working artifact og kun arbejdsmodel.
- PDR-002 kvalificerer Governance/Specification-kildernes faktiske lifecycle og autoritet.

## Aktuelle blockers

- Constitution/Governance activation, named owners, approval bodies, stable IDs og effective dates.
- Specification GI-015, regulatory/QMS, privacy/security og clinical safety authority.
- Architecture er non-active; ingen ADR er accepted; formel LEX og traceability enforcement mangler.
- Product owner, Consultation Impact Standard, ekstern klinikerevidens og kompetent clinical safety/content authority mangler.
- PEV-001-H01 F-01–F-05 og Sprint 1 Architecture-handoff S1-AH-01–10 er ikke disponeret; detailed design og Build-start er blokeret.
- P01-prototypen er en untracked working-tree state; Sprint 1.1-comparators mangler stable identity, external clinician evidence og clinical content/safety authority.
- P02-baseline er version-locked, men Sprint 1.2 mangler external evidence, IA/state-semantic review og et repository-resident Build authorization record for næste scope.
- C3 er Architecture-kvalificeret som bounded prototype, og C3-FIX-001 v1.1 er klinisk founder-reviewed og locked. Kun separat Steering Build-authority foreligger endnu ikke; se PI-047.
- C3.2 er Product-reconciled og conditionally buildable med locked scenario; kun separat Steering Build authority og navngiven Build owner mangler. Se PI-048.
- Repositoryet indeholder allerede unrelated modified/untracked Build-, Architecture-, prototype- og governancearbejde; Product-adoptionen må ikke attestere eller ændre det.

Detaljer og closure-evidens findes i [Product Issue Register](registers/product-issue-register.md).

## Næste leverance

**Product anbefaler, at Steering kan udstede Build authority for præcis [C32-PBH-001 v1.0](handoffs/C3-2-PRODUCT-TO-BUILD-HANDOFF-v1.0.md) og `C32-FF-SCENARIO-001@1.0`.** API-018, Product reconciliation, comparator lock og scenario lock er gennemført.

Clinical Workflow Architecture kan fortsætte efter Steering-disposition af Experience Vision-gatet. Konkrete skærme, navigation, controls, Sprint 1-build og implementation handoff er fortsat ikke autoriseret.
