## 1. Koder

- **OB:** Observeret adfærd — synlig handling eller hændelse
- **DU:** Deltagerudsagn — ordret eller tydeligt markeret parafrase
- **AI:** AI-evaluering — data fra AI-agentscenarie eller AI-output, ikke menneskeobservation
- **RI:** Research-fortolkning — analytisk forklaring, aldrig rådata
- **H:** Facilitatorhjælp — H0 ingen; H1 neutral gentagelse; H2 generelt prompt; H3 procedureforklaring
- **T:** Tøven — mindst 5 sekunders pause uden målrettet handling
- **E:** Fejl — observerbart resultat afviger fra udtrykt mål
- **BN:** Tilbage-navigation
