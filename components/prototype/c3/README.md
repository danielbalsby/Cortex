# C3 Calm Clinical Workflow

Route: `/prototype/c3-calm-clinical-workflow`

C3 is an isolated synthetic learning comparator. It composes the unchanged
Sprint 1.1 History/Objective types and reducer with separate prototype-local
records for clinician-owned Assessment, reviewed phrase commitments, output
intent, manual drafts and recovery metadata.

It does not replace C0–C2.2, use real patient data, provide clinical decision
support, generate referrals or establish clinical validity.
